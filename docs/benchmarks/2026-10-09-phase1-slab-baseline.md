## Environment

Same reference sandbox as the phase-1 mmap baseline (kata-containers VM,
virtualized Xeon, 2 vCPU, 3200 MHz nominal, 4 GiB cgroup): absolute rates
are environment-bound (U-012; ceiling ~2.9 GB/s for any large traversal).

## Numbers

### `PageSlab/coordinate_extraction_1M_glyphs` (20 repetitions)

One pass summing the four SoA coordinate arrays (x/y/w/h) of a live,
warm, 32-byte-aligned 1M-glyph slab — the audit's "coordinate extraction
latency" workload (its "cache hit rate" needs PMU counters, U-010).

| metric | value |
|---|---|
| mean | 0.614 ms per 1M-glyph pass |
| P50 / P90 / P99 | 0.613 / 0.619 / 0.620 ms |
| CV | 0.55 % |
| rate | mean **1.71 × 10⁹ glyphs/s** = **0.585 ns/glyph** (~1.9 cycles @ 3.2 GHz) |

16 bytes of coordinates per glyph at 0.585 ns/glyph ≈ 27 GB/s of
logical float traffic — the four-way SoA layout is wide enough to
saturate this environment with a single scalar-per-array pass.

### `PageSlab/build_1M_glyphs` (20 repetitions)

Unboxing a glyph source into the slab (zero-fill + memcpy of ~20 MB +
structure writes + bitwise CRC-32) plus the arena reset, per pass.

| metric | value |
|---|---|
| mean | 199.7 ms per 1M-glyph pass |
| P50 / P90 / P99 | 199.4 / 200.6 / 202.0 ms |
| CV | 0.44 % |
| rate | mean **5.25 × 10⁶ glyphs/s** = **190 ns/glyph** |

## Method notes

1. **The bitwise CRC dominates build time.** The zero-fill + memcpy
   traffic (~40 MB) accounts for roughly 15–20 ms at this environment's
   ceiling; the remaining ~180 ms is the 8-iterations-per-byte bitwise
   CRC-32 over ~20 MB. A table-driven (or CRC32 instruction) variant
   would cut that ~8× — deliberately deferred: task 1.3's acceptance is
   layout/alignment, not build speed, and no audit gate covers build.
   Revisit when Phase 2/3 ingestion makes slab construction hot.
2. **Extraction rate is the durable number**: 0.585 ns/glyph is within
   ~2× of the environment's bare traversal ceiling measured in the mmap
   baseline's control experiment — i.e. the UPS layout itself costs
   almost nothing per glyph once warm.
